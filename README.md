# JW Control de Plagas

Sitio web de fumigación y control de plagas profesional en El Salvador.

## Deploy en Vercel

1. Ir a [vercel.com](https://vercel.com)
2. Importar repositorio: `proyecto_control_de_plagas_jw`
3. Framework Preset: **Other** (sitio estático)
4. Sin build command, directorio raíz: `/`
5. Click **Deploy**

## Nota sobre imágenes

Agregar la imagen `hero-jw.jpg` en la carpeta `/images/` del repositorio para que aparezca en el hero.
